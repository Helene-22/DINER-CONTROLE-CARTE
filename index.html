Cartes imprimées

Enregistre dans l'application les codes QR déjà imprimés sur les cartes (S-0001 à S-0700, G-0001 à G-0200, VIP-0001 à VIP-0100), pour qu'ils soient reconnus dès le premier scan.
Zone sensible
Efface TOUTES les cartes actuellement enregistrées (y compris celles déjà payées/entrées et les cartes créées manuellement), puis réimporte uniquement S-0001 à S-0700, G-0001 à G-0200, VIP-0001 à VIP-0100. Action irréversible.

Importer un fichier Excel

Importez le fichier .xlsx des codes QR par catégorie (colonnes Code / Catégorie / Montant) pour les enregistrer directement dans l'application — pratique pour un autre lot de cartes imprimées.
